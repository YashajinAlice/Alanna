# 更新記錄

## 版本 0.0.0.14 (2025-03-23)
### 新增功能
- 添加票口系統，允許用戶創建支援票口
- 添加儲存對話紀錄按鈕，支援人員可將對話記錄發送到自己的DM
- 添加關閉票口模態表單，可直接輸入關閉原因
- 添加 bot-info 命令，顯示機器人資訊和近期更新
- 添加多語言支持系統
- 添加伺服器設置系統
- 添加自動角色分配功能
- 添加歡迎訊息自定義功能

### 改進
- 改進票口關閉流程，使用模態表單輸入關閉原因
- 修復票口系統中的互動回覆衝突問題
- 優化票口記錄功能，支持將對話保存為文本文件
- 改進命令結構，使用分類文件夾
- 優化數據庫系統，支持伺服器和用戶設置
- 添加命令使用統計功能

### 修復
- 修復當沒有輸入關閉原因時的處理邏輯
- 修復模態表單處理程序衝突問題
- 修復互動回覆多次導致的錯誤
- 修復語言切換時的錯誤
- 修復權限檢查邏輯
- 修復事件處理程序註冊問題
